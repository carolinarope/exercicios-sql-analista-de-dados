# SQL Básico — Consultas e Agregações

Esta pasta reúne exercícios de SQL para praticar consultas e manipulação de dados em cenários de clientes, produtos e vendas.

## Exercícios

### 01 — Análise de clientes

Arquivo: `01_analise_clientes.sql`

Prática de consultas com `SELECT`, seleção de colunas, filtros com `WHERE`, buscas com `LIKE` e condições envolvendo status, localização e data de cadastro.

### 02 — Análise de produtos

Arquivo: `02_analise_produtos.sql`

Prática de ordenação com `ORDER BY`, limitação de resultados com `LIMIT`, seleção de valores distintos com `DISTINCT` e filtros com `WHERE` e `BETWEEN`.

### 03 — Análise de vendas

Arquivo: `03_analise_vendas.sql`

Exercício com uma tabela de vendas e consultas de agregação utilizando `COUNT`, `SUM`, `AVG` e `MAX`, além de `GROUP BY`, `HAVING` e `ORDER BY`.

## Como executar

Abra o arquivo desejado no MySQL Workbench e verifique os comentários e pré-requisitos antes de executá-lo.

Os exercícios de clientes e produtos pressupõem a existência das tabelas consultadas. O exercício de vendas utiliza o banco `mydb` e cria uma tabela de exemplo. Confira o banco selecionado antes da execução.

## Objetivo

Praticar a construção de consultas SQL, compreender os resultados dos filtros e utilizar agregações para responder a perguntas sobre os dados.

Os arquivos representam exercícios de aprendizagem.
