# Estudos de SQL e Modelagem Relacional

Repositório de atividades práticas desenvolvidas durante meus estudos de SQL e bancos de dados relacionais. O objetivo é registrar minha evolução em consultas, modelagem de dados e manipulação de registros utilizando MySQL.

Os exercícios fazem parte da minha formação em tecnologia e demonstram conceitos aplicados em cenários acadêmicos, como uma plataforma de jogos, um campeonato de kart e consultas de vendas.

## Tecnologias e ferramentas

- MySQL
- MySQL Workbench
- SQL: criação e manipulação de dados
- Modelagem relacional
- Chaves primárias e estrangeiras
- Consultas com filtros, junções e agregações

## Organização do repositório

### [01 — Básico](01-basico/README.md)

Exercícios de consultas sobre clientes, produtos e vendas, incluindo filtros, ordenação, seleção distinta e funções de agregação.

### [02 — Modelagem relacional](02-modelagem-relacional/README.md)

Atividade de modelagem e manipulação de um banco de dados para uma temporada de corridas de kart, com tabelas relacionadas, inserções, atualizações e exclusão de dados.

### [03 — Consultas relacionais](03-consultas-relacionais/README.md)

Atividade da TDS Cloud Gaming, com tabelas de usuários, jogos, desenvolvedoras, categorias e biblioteca, além de consultas com `JOIN`, `LEFT JOIN` e funções de agregação.

## Como executar

1. Instale o MySQL Server e o MySQL Workbench.
2. Abra o arquivo `.sql` da atividade desejada no Workbench.
3. Leia os comentários e verifique o banco de dados que será criado ou utilizado.
4. Execute o script em um ambiente de teste apropriado e confira os resultados das consultas.

Os scripts de criação e povoamento devem ser executados com atenção às tabelas existentes. Evite executar repetidamente um script que cria tabelas e insere registros sem verificar o estado do banco.

## Objetivo de aprendizagem

Consolidar fundamentos de SQL e modelagem relacional, compreender como as tabelas se relacionam e praticar operações comuns em bancos de dados utilizados por aplicações.

Este repositório reúne exercícios de estudo, não sistemas de produção nem experiência profissional.
